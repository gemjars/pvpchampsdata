KIT TOURNAMENT TRACKER - SETUP GUIDE
=====================================

How to move this app to a new machine and start using it.

1. ZIP THE FOLDER
------------------
Zip everything in this folder EXCEPT the "node_modules" folder (it's large
and gets regenerated automatically). Make sure the zip includes:
  - index.html
  - styles.css
  - app.js
  - server.js
  - package.json
  - package-lock.json
  - data/matches.json   (keeps your existing match history)

2. TRANSFER AND EXTRACT
------------------------
Copy the zip file to the new machine and extract it to any folder, e.g.
  C:\Users\<you>\Documents\testproject

3. INSTALL NODE.JS (if not already installed)
-----------------------------------------------
Check first by opening a terminal and running:
  node -v

If that fails, install Node.js LTS from https://nodejs.org
(or on Windows: winget install OpenJS.NodeJS.LTS)
Any Node.js version 18 or newer works.

4. INSTALL DEPENDENCIES
-------------------------
Open a terminal in the extracted folder and run:
  npm install

This recreates the "node_modules" folder (just the Express library) using
package-lock.json.

5. START THE SERVER
---------------------
In the same terminal, run:
  npm start

You should see:
  Kit Tournament Tracker running at http://localhost:3000

Leave this terminal window open - the server must keep running while you
use the app.

6. OPEN THE APP
-----------------
Go to this address in your browser:
  http://localhost:3000

7. USE THE APP
-----------------
- Match History tab: enter both player names, choose the format (Best of 3
  or Best of 5), pick each player's kit(s), then click "Set Up Games" and
  enter scores one kit at a time. Kits after the current one stay locked
  until you fill in the previous kit's score, and once a player has
  clinched the match, any remaining kits (including the decider) are
  automatically marked "Not needed" and skipped. Click "Save Match" once
  the match is decided.
- Players tab: pick a player from the dropdown to see their win/loss
  record, kit-pick stats, and full match history.
- Kits tab: see how often each kit was picked, by whom, how often it was
  used as the decider, and win rates.

NOTES
-------
- All match data is stored in data/matches.json. Back up or copy this file
  to preserve or transfer your match history between machines.
- To stop the server, press Ctrl+C in its terminal. To restart later, run
  "npm start" again from this folder.
- If port 3000 is already in use on the new machine, start on a different
  port, for example:
    $env:PORT=3001; npm start
  then browse to http://localhost:3001 instead.

8. STANDALONE .EXE (no Node.js install needed)
-------------------------------------------------
If you'd rather hand someone a single file that just runs (no Node.js,
no "npm install"), build a standalone Windows executable:

  a) In this project folder (with node_modules already installed), run:
       npm install --save-dev "@yao-pkg/pkg"
       npm run build

  b) This creates dist\kit-tournament-tracker.exe - a single file with
     Node.js and the whole app bundled inside.

  c) Copy just that .exe to any Windows machine (any folder) and
     double-click it, or run it from a terminal:
       .\kit-tournament-tracker.exe

  d) It starts the same server at http://localhost:3000. It creates its
     own "data" folder (with matches.json) next to wherever the .exe is
     placed, so match history persists between runs as long as you keep
     using the same copy of the .exe from the same folder.

  e) To use a different port:
       $env:PORT=3001; .\kit-tournament-tracker.exe

  Note: the build in step (a) only needs to happen once, on a dev
  machine with Node.js installed. The resulting .exe itself needs
  nothing installed on the machines it's copied to. To rebuild after
  changing the app's code, just run "npm run build" again.
